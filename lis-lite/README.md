# 多医院互联 LIS 检验信息系统（精简版）

面向多医院协同检验流程的简体中文演示实现。

## 已覆盖模块

- 标本接收、唯一条码与状态流转
- 检验项目、收费编码、参考区间和危急阈值
- HL7 ORU^R01 文本帧模拟接收与 ACK
- 质控批次：失控自动锁定同批待签发报告
- 结果审核：危急值强制两名不同审核人双签
- 报告 HTML 模板（可作为 PDF 渲染输入）
- 院内与合作机构双向转检，实施最小必要字段脱敏
- 关键动作审计留痕

## 快速验收

```bash
npm run 验收
```

详细架构与数据模型见 [docs/架构与数据模型.md](docs/架构与数据模型.md)。
